# 84 — Hub Annuaire, Marketplace et Réservations Mansa : mini-sites commerçants, catalogue, commandes, rendez-vous, paiements, livraison, avis, promotions et administration centralisée

## 1. Objet du document

Ce document définit le cahier des charges complet du Hub Annuaire Mansa.

Le Hub doit combiner plusieurs logiques :

- un annuaire professionnel ;
- une marketplace de produits ;
- une plateforme de services ;
- un système de réservation ;
- un système de rendez-vous ;
- un outil de création de mini-sites commerçants ;
- un moteur de recherche local ;
- un espace de découverte ;
- un canal de paiement Mansa ;
- un outil de fidélisation ;
- un canal publicitaire et promotionnel.

Le fonctionnement doit s’inspirer des usages de plateformes comme :

- Shopify pour la création et la gestion d’une boutique ;
- Planity pour la réservation de prestations ;
- Google Maps pour la recherche locale ;
- Deliveroo ou Uber Eats pour certaines commandes et livraisons ;
- Booking pour certaines réservations ;
- les marketplaces classiques pour le catalogue, les commandes et les avis.

Le Hub doit rester entièrement intégré à l’écosystème Mansa.

## 103. Règles métier

1. Aucun commerce non autorisé ne peut être publié.
2. Chaque commerce public possède un propriétaire vérifié.
3. Chaque produit appartient à un commerce.
4. Chaque service appartient à un commerce.
5. Chaque créneau est vérifié avant confirmation.
6. Une réservation confirmée bloque le créneau.
7. Un paiement ne peut être exécuté deux fois.
8. Une commande possède une référence unique.
9. Les avis doivent être liés à une expérience vérifiée.
10. Les remboursements passent par le Ledger.
11. Les données client sont minimisées.
12. Les contenus sponsorisés sont identifiés.
13. Les prix sont affichés avant paiement.
14. Les règles d’annulation sont visibles avant confirmation.
15. Les promotions ont une date de validité.
16. Les employés ont des permissions limitées.
17. Les modifications critiques sont auditées.
18. Les comptes suspects peuvent être suspendus.
19. Jini ne valide pas seul une action sensible.
20. Les fonctionnalités sont activables par pays et par offre.

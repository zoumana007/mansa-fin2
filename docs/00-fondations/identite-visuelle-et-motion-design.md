# Identité visuelle et expérience Mansa

## 1. Positionnement visuel

Mansa doit transmettre immédiatement quatre sensations :

- confiance financière ;
- technologie avancée ;
- identité africaine moderne ;
- simplicité d’utilisation.

L’interface ne doit pas ressembler à une copie de Revolut, Apple ou Stripe. Elle peut reprendre leur niveau de qualité, tout en conservant une identité propre à Mansa.

## 2. Direction artistique principale

Le style officiel de Mansa reposera sur une combinaison maîtrisée de :

- Liquid Glass ;
- glassmorphism ;
- dégradés Aurora ;
- profondeur 3D ;
- cartes flottantes ;
- micro-interactions ;
- animations lumineuses discrètes ;
- surfaces transparentes réactives.

Les effets de verre ne doivent pas être appliqués partout. Ils doivent principalement servir pour :

- les barres de navigation ;
- les panneaux secondaires ;
- les cartes d’actions ;
- les menus flottants ;
- les fenêtres modales ;
- les notifications ;
- certains éléments du site vitrine.

Les écrans contenant des informations financières importantes doivent rester très lisibles.

## 3. Différence entre le web et les applications

### Site web Mansa

Le site web constitue la vitrine spectaculaire de l’écosystème.

Il pourra intégrer :

- objets et téléphones en 3D ;
- cartes bancaires flottantes ;
- mouvements réagissant au curseur ;
- parallaxe pendant le défilement ;
- particules lumineuses ;
- dégradés animés ;
- transitions cinématographiques ;
- statistiques animées ;
- présentation interactive des différents produits Mansa ;
- carte ou globe 3D montrant le Mali et l’expansion régionale.

Niveau d’animation recommandé : élevé, immersif et premium.

### Applications mobiles

Les applications doivent rester plus simples, rapides et rassurantes.

Elles intégreront principalement :

- transitions fluides entre les écrans ;
- micro-interactions sur les boutons ;
- retour haptique ;
- animations de paiement ;
- animation des cartes bancaires ;
- validation visuelle des opérations ;
- graphiques progressifs ;
- skeleton loaders ;
- notifications fluides ;
- effets Liquid Glass légers ;
- animations QR et NFC ;
- transitions partagées entre certains éléments.

Niveau d’animation recommandé : modéré, fonctionnel et performant.

### Portail administrateur

Le portail administrateur doit privilégier :

- la densité d’information ;
- la rapidité ;
- la lisibilité ;
- la supervision ;
- les tableaux et graphiques ;
- les animations discrètes uniquement.

## 4. Palette provisoire Mansa

### Couleurs principales

- Bleu nuit profond : fonds principaux et sécurité.
- Cyan technologique : actions, données actives et lumière.
- Violet premium : innovation et intelligence artificielle.
- Vert de validation : paiements réussis et sécurité.
- Blanc légèrement bleuté : textes principaux.

### Couleurs financières

- Vert : opération réussie ou entrée d’argent.
- Rouge : erreur, blocage ou sortie critique.
- Orange : avertissement ou action en attente.
- Bleu : information neutre.
- Violet : IA, automatisation ou fonctionnalité premium.

Les couleurs ne doivent jamais être le seul moyen de transmettre une information. Une icône et un texte doivent également être présents.

## 5. Formes et surfaces

### Coins arrondis

- Petits composants : 10 à 14 px.
- Boutons et champs : 14 à 18 px.
- Cartes : 18 à 26 px.
- Grandes fenêtres : 24 à 32 px.

### Verre transparent

Chaque surface de verre doit comporter :

- une transparence contrôlée ;
- un flou d’arrière-plan ;
- une bordure lumineuse fine ;
- une ombre douce ;
- un contraste suffisant ;
- une version de secours sur les appareils moins puissants.

## 6. Mouvement et animation

Les animations Mansa doivent être :

- fluides ;
- naturelles ;
- rapides ;
- cohérentes ;
- utiles ;
- interrompables ;
- compatibles avec le mode réduction des animations.

### Durées recommandées

- Retour immédiat au toucher : 80 à 140 ms.
- Boutons et petits éléments : 160 à 220 ms.
- Modales et panneaux : 220 à 320 ms.
- Navigation entre écrans : 250 à 400 ms.
- Animation de paiement : 500 à 1 200 ms.
- Animation marketing ou 3D : durée libre mais non bloquante.

### Principes obligatoires

- Les actions critiques ne doivent jamais dépendre d’une animation.
- Une animation ne doit jamais retarder artificiellement un paiement.
- Les montants et confirmations doivent rester lisibles.
- Les animations lourdes doivent être désactivables.
- Le site doit conserver une version fluide sans 3D.
- Les appareils peu puissants doivent recevoir une expérience allégée.

## 7. Animations emblématiques Mansa

### Paiement réussi

1. Le bouton se contracte légèrement.
2. Une onde lumineuse se propage.
3. Une vérification sécurisée apparaît.
4. Une coche animée confirme le paiement.
5. Le téléphone produit un retour haptique.
6. Le reçu apparaît depuis le bas de l’écran.

### Carte bancaire

- légère inclinaison selon le mouvement ;
- reflet dynamique ;
- retournement pour afficher les informations autorisées ;
- animation de gel et dégel ;
- pulsation légère pendant un paiement NFC.

### Transfert d’argent

- le montant se déplace visuellement vers le destinataire ;
- l’avatar du destinataire s’illumine ;
- la confirmation apparaît immédiatement ;
- le nouveau solde s’actualise progressivement.

### Intelligence artificielle Jini

- halo violet et cyan discret ;
- formes lumineuses réactives ;
- animation de réflexion non bloquante ;
- voix et texte synchronisés lorsque cette fonction est active.

## 8. Technologies recommandées

### Web

- Next.js ;
- Framer Motion ;
- GSAP ;
- Three.js ou React Three Fiber ;
- Spline lorsque pertinent ;
- CSS moderne ;
- Lottie ou Rive.

### Applications React Native

- React Native Reanimated ;
- Moti ;
- Gesture Handler ;
- Lottie ou Rive ;
- bibliothèques haptiques natives ;
- animations natives lorsque nécessaire.

### Application TPE Android

- Jetpack Compose ;
- MotionLayout lorsque nécessaire ;
- animations Android natives ;
- retour sonore et haptique configurable.

## 9. Accessibilité et performance

Le système devra respecter :

- le mode clair et le mode sombre ;
- les contrastes accessibles ;
- la réduction des mouvements ;
- les tailles de texte dynamiques ;
- les lecteurs d’écran ;
- la navigation clavier sur le web ;
- les performances sur les téléphones d’entrée de gamme ;
- l’économie de batterie ;
- le chargement progressif des objets 3D.

## 10. Règle finale

Le web peut impressionner.

Les applications doivent rassurer.

Le portail administrateur doit informer.

Toutes les interfaces doivent cependant appartenir clairement à la même marque Mansa.
